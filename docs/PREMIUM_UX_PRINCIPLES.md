# Principes UX Premium TENNET

TENNET doit rester simple devant et intelligent derriere.

Regles produit :
1. Privilegier une action claire plutot qu'un tableau complexe.
2. Privilegier une recommandation plutot qu'un choix technique.
3. Privilegier un statut lisible plutot qu'un code interne.
4. Privilegier un workflow guide plutot qu'un ecran vide.
5. Demander une confirmation humaine seulement quand elle est utile.
6. Envoyer en revue manuelle seulement quand TENNET doute.
7. Preferer un import intelligent au renommage manuel.
8. Garantir une interface mobile exploitable sur le terrain.

TENNET ne garantit pas le remboursement. TENNET garantit la detection, le suivi, la revue et la tracabilite des pertes detectees.

OpenAI, Gmail et AutoPilot restent controles par configuration. Aucun envoi automatique n'est active par defaut.
